# 剖面构造：任意固定有限 K 的剖面引理链

以下所有选参均按 `固定 K,μ → 小 σ → 大偶数 n → 小截断/修复 → 大周期 T` 的顺序。μ>1/2。常数允许依赖前面已经固定的量。

核的完整定义为：`I_C(x)=∫_0^x C(y)dy+∫_x^∞e^(x-y)C(y)dy`，`I_E(x)=∫_0^x[1−e^(y-x)/2]E(y)dy+(1/2)∫_x^∞e^(x-y)E(y)dy`，`Kcal=2λI_C−2I_E`。半线衰减剖面取 λ=2E_tot/C_tot；周期剖面取 λ=2Ebar/Cbar。

## 引理 1：精确零矩与严格电流

取偶数 n≥4K+4，`h=x^(n/2)(x-2ni)^n exp[(-σ+i/4)x]`，`z=P_K(D)h`，`P_K(D)=∏_(s=1)^K(D-s)`。原点零阶至少 n/2-K≥2，且无穷远指数衰减，全部 K 次分部积分的边界项为零，故 `∫e^-sx z=P_K(s)∫e^-sx h=0` (s=1,...,K)。

设 p 多项式根均在闭上半平面，c=-σ+i/4。在下半平面有 Im(p'/p)>0，而方程 `(D+c-s)p=0` 在非根点要求 `p'/p=-(c-s)`，右边虚部 -1/4；不可能成立。实轴非根点同理，因为 Im(p'/p)≥0。原有实根只能由重数降低一后保留。由归纳，滤波后多项式在 x>0 无根（原多项式在正实轴无根）。于是

`Im(z'/z)=1/4+Σ_ρ Imρ/|x-ρ|²≥1/4`，

故 `C=Im(conj(z)z')>0` 于 x>0。根的重数按重复计数；这避免了选择相位时的零点问题。

## 引理 2：两个权重的鞍点极限

置 y=x/(2n)、θ=1/(2n)，`B_σ=l_0-σ+ik_0`，其中

`l_0=(1+3y²)/[4y(1+y²)]`，`k_0=(y²+3)/[4(1+y²)]`。

确有 h'/h=B_σ。令 R_0=1，`R_(j+1)=(B_σ-j-1)R_j+θ∂_yR_j`，则 z/h=R_K。

对加权积分 `∫e^-sx|z|²g(y)dx` (s=0 或 1)，略去共同常数后的指数是

`n f_s(y)`，`f_s=log y+log(1+y²)-(4σ+2s)y`。

其二阶导数为 `4l'_0=-(1+3y⁴)/[y²(1+y²)²]<0`。所以唯一临界点 y_s 是唯一非退化全局最大点；两端 f_s→−∞。固定 K、σ 后，R_K→P_K(B_σ) 于内紧集的任意有限 C^m 范数，且该极限在最大点非零（B_σ 的虚部为正）。在两端，R_K 及其所需导数至多有固定阶 y^-1 或 y 的多项式增长，因而被 y^n 和 exp[-n(4σ+2s)y] 吸收。将积分分成最大点小邻域、其余紧集和两端，后两部分相对主项指数小；小邻域用二阶 Taylor 及 dominated convergence。这给出通常的 Laplace 比值极限，而无需 n 一致到 K→∞。

取 g 为 k_n=Im(z'/z) 和 |z'/z|²，得到

`λ(n,σ)=2 E_tot/C_tot → Λ_σ=2k_0(y_b)`，`l_0(y_b)=σ`；

`E_L/(2C_L) → T_σ=[1/4+k_0(y_w)²]/[2k_0(y_w)]`，`l_0(y_w)=σ+1/2`。

隐函数展开给 `Λ_σ=1/2+(16/9)σ²+O(σ⁴)`、`T_σ=1/2+σ²+O(σ³)`。故先取 σ>0 小，使 Λ_σ<μ 且 Λ_σ-T_σ>0；再取 n 大，保留两条严格不等式。由 `Kcal(0)=2λC_L-E_L` 得 Kcal(0)>0。

## 引理 3：整个半直线只有一次变号

置 u=y/(1+y)，`Rtilde_j=u^j R_j`。它满足精确递推

`Rtilde_(j+1)=[uB_σ-(j+1)u-jθ(1-u)²]Rtilde_j+θu(1-u)²∂_uRtilde_j`。

uB_σ 在 [0,1] 光滑。θ=0 时 `Rtilde_K=∏_(s=1)^K[u(B_σ-s)]`；内部各因子的虚部非零，左端为 4^-K，右端为 P_K(-σ+i/4)。因此固定 K、σ 近零时，在闭区间上其绝对值有正下界，θ 小后仍然如此。

精确对数导数为

`z'/z=B_σ+θ(1-u)²[(∂_uRtilde_K)/Rtilde_K-K/u]`。

所以 u·Re(z'/z) 及 Im(z'/z) 在闭区间上光滑且随 (σ,θ)→0 于任意所需有限阶一致收敛。令 l_n+ik_n=z'/z，

`J_n=λ[(1+2l_n)k_n+θ∂_yk_n]-l_n²-k_n²`。

则 u²J_n 在 C¹([0,1]) 收敛到 u²J_0，

`J_0=(y-1)Q(y)/[16y²(1+y²)²]`，

`Q=y⁵+y²(4y²-3y+1)+(6y²-2y+1)>0`。

两个二次多项式判别式均负且首项正。极限左右端值为 -1/16、1/16，唯一零点 u=1/2 简单。因此选一个小零点邻域，在其中极限导数有正下界，外面函数绝对值有正下界。C¹ 小扰动保证邻域中恰一个零点、外面无零点。选参仍是先小 σ、再大 n（同时满足引理 2）。

## 引理 4：全过程 Kcal>0

令 `Hscr=λ(F+C)-P_E`，F=∫_0^xC、P_E=∫_0^xE，则 `Hscr'=|z|²J_n`。它从 0 先严格下降再严格上升，终值为 E_tot>0，故自身恰有一个负到正零点 x_h。

直接对核求导得 `Kcal''-Kcal=-2Hscr`，`Kcal'(0)=Kcal(0)>0`，`Kcal(∞)=2E_tot>0`。在 [0,x_h]，只要 Kcal>0 就有 Kcal''≥Kcal>0，故不可能首次触零。若在 (x_h,∞) 取非正值，由正终值必有非正内部最小点，但此点 `Kcal''=Kcal-2Hscr<0`，矛盾。于是所有 x≥0 严格正，且连续性和正终值给 inf Kcal>0。

## 引理 5：紧支撑修复与平坦周期化

用实非负光滑 χ 截去原点和无穷远小尾部。原点高阶零及无穷远衰减保证 χz→z 于 H¹，故 E、C 于 L¹ 收敛；`C_(χz)=χ²C≥0`。有限个 Laplace 矩误差趋零。

在固定内部严格正电流紧区间取 K 个窄、积分为 1 的实 bump，中心 x_j 互异。矩阵 `A_sj=∫e^-sx b_j` 趋于 `e^-s x_j`，其行列式是非零 Vandermonde。因此固定足够窄的 bumps 后 A 有有界逆。解 K 个复系数修复零矩；系数随截断误差趋零。只在严格电流核心改动，C¹ 小扰动保持 C≥0。λ 以及 Kcal 对 (E,C) 的 L¹ 变化连续，且核有界，所以保持 λ<μ 与 inf Kcal>0。

取 T 大于紧支撑右端，支撑与 0,T 保持正距离，周期延拓。单周期总能量和电流给相同 λ。对 0≤x≤T：

`Kcal_per(x)=Kcal_compact(x)+e^(x-T)/(1-e^-T) Kcal_compact(0)>0`；

`Kcal_per(x+T)-Kcal_per(x)=2E_per+e^-x∫_0^T e^(y-T)E(y)dy>0`。

半线矩等于单周期矩除以 1-e^-sT，故仍为零。得到光滑、周期端点开邻域平坦的剖面。

最后把相同内部 bumps 的复方向按其半线矩矩阵取逆，得到 M(z_c)=c 的 2K 维实族。缩小 c 球，核心 strict current、λ<μ、全半线 Kcal>0 均保留。后者先在 [0,T] 上由紧性保留，再用上面的正周期增量传播。

## 判定

引理 1–5 给出 非线性提升/半径正性 所需的完整固定 K 剖面族。任意给定 K、μ>1/2 均可实施；全部常数和参数次序明确，未声明有效复杂度界或无限阶一致性。
