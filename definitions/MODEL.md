# 模型、公式和命题定义

## RECCVS-D001：归一化

签名 (-,+,+,+)，Λ=0，磁荷为零，固定电耦合 e≠0。用

\[
S=\int\sqrt{-g}\,[R-F_{ab}F^{ab}-2g^{ab}D_a\phi\overline{D_b\phi}]\,d^4x,
\quad F=dA,\quad D=\nabla+ieA.
\]

忽略共同作用量常数。变分给

\[
G_{ab}=2T^{EM}_{ab}+2T^{SF}_{ab},\quad
T^{EM}_{ab}=F_{ac}F_b{}^c-\tfrac14g_{ab}F^2,
\]
\[
T^{SF}_{ab}=\Re(D_a\phi\overline{D_b\phi})-\tfrac12g_{ab}|D\phi|^2,
\quad D^aD_a\phi=0,\quad
\nabla_aF^{ab}=e\Im(\bar\phi D^b\phi).
\]

规范 A→A+dχ，φ→exp(-ieχ)φ。正/负电荷的取向可整体翻转，不改变极端性。Maxwell 方程若写成 ∇^aF_{ba} 则右侧反号。

双零度量及取向固定为

\[
g=-\Omega^2du\,dv+r^2d\omega^2,
\quad g_{uv}=-\Omega^2/2,\quad
\nu=r_u,\ \lambda=r_v,\quad F_{uv}=\frac{\Omega^2Q}{2r^2}.
\]

未来 u,v 增加；常 u 是出射零面。此电荷取向专门使下面 Q_v 与用户形成包的电流相同。A_v=0 时 ∂_vA_u=-Ω²Q/(2r²)。若源文采用正号 ∂_vA_u，必须同时翻转 Q 或耦合/复共轭，不能只复制一个 Maxwell 分量。

| 量/方程 | 本项目公式 |
|---|---|
| Hawking 质量 | m=r(1+4Ω^{-2}νλ)/2 |
| 重整化质量 | ϖ=m+Q²/(2r) |
| RN 关系 | 1-2ϖ/r+Q²/r²=-4Ω^{-2}νλ |
| 出射 Raychaudhuri | ∂_v(Ω^{-2}λ)=-rΩ^{-2}|D_vφ|² |
| 入射 Raychaudhuri | ∂_u(Ω^{-2}ν)=-rΩ^{-2}|D_uφ|² |
| 半径混合方程 | r_uv=-νλ/r-Ω²(1-Q²/r²)/(4r) |
| 电荷 | Q_v=e r² Im(φ overline{D_vφ}), Q_u=-e r² Im(φ overline{D_uφ}) |
| 波方程 | (D_uD_v+D_vD_u)φ+2νD_vφ/r+2λD_uφ/r=0 |
| 共变导数交换 | [D_u,D_v]φ=ieF_uvφ |
| 共形因子 | (log Ω²)_uv=-2Re(D_uφ overline{D_vφ})+Ω²/(2r²)+2νλ/r²-Ω²Q²/r⁴ |
| 质量通量 | ϖ_u=-2r²Ω^{-2}λ|D_uφ|²+(Q/r)Q_u；ϖ_v=-2r²Ω^{-2}ν|D_vφ|²+(Q/r)Q_v |
| 膨胀 | θ_L=2L(r)/r，θ_underlineL=2underlineL(r)/r；严格陷俘为两者均负 |

这些方程只在 r>0 的坐标区域直接使用；中心用笛卡尔正则场或相容 Taylor 延拓。质量通量含 Q Q_a/r，不能把 ϖ 当成两个方向都单调的量。

文献转换：AKU/Gajic 常用 D=∇-iqA，耦合记 q；用户包用 e，部分论文把 e 记为背景电荷。本项目写 e（耦合）、Q（电荷）、σ=|Q_f|/M_f（终态比值）。Gajic–Luk 的 8π 与场尺度需在调用前按作用量转换；只比较未转换的 |e|M 数值不合法。单位缩放为 g→a²g，A→aA，e→e/a，M,Q,r→a(M,Q,r)；因此 eM 不变。固定 e 的初值空间中不能任意用缩放制造曲率。

## RECCVS-D002：约束初值空间

数据 Ψ=(h,K,E,φ₀,Π)，Σ≅R³，Π=D_nφ，球对称，无磁场；电磁势选择固定径向规范。约定 K_ij=-g(∇_i n,∂_j)。设 T=T_EM+T_SF，ρ=T(n,n)，j_i=-T(n,∂_i)。约束为

\[
R(h)+(trK)^2-|K|^2=4\rho,\quad
\nabla^j(K_{ij}-h_{ij}trK)=2j_i,\quad
div_h E=e\Im(\phi_0\bar\Pi).
\]

这里 E_i=F_{ai}n^a，与上面 Q 的取向一致。ρ=(|E|²+|Π|²+|D_Σφ|²)/2。中心要求 h、K、复标量及电场在笛卡尔坐标光滑、h正定、无锥角；径向光滑标量有偶 Taylor，E=O(r)，Q=O(r³)，m=O(r³)。Q(0)=0，禁止插入点电荷。

AF 要求固定渐近坐标中 h-δ=O(r^{-1})、∂h=O(r^{-2})，K=O(r^{-2})，E=Q_ADM r^{-2}∂_r+O(r^{-3})；标量先用紧支撑数据，后扩展到明确带权空间。空间 h 完备，初始非中心球 θ_out>0、θ_in<0。事件视界不交 Σ 是另一独立全局命题；本定义不偷偷包含它。

拓扑先固定 s≥6：在固定 AF chart 和中心 chart 的规范切片上，将 ADM/Coulomb 1/r、1/r² 主项作为有限参数，余项用 H^s_δ、K/Π 用 H^{s-1}_{δ+1}。采用
\[
\|f\|_{H^k_\delta}^2=\sum_{j=0}^k\int (1+r)^{2(\delta+j)}|\partial^jf|^2dx,
\qquad -3/2<\delta<-1/2.
\]
主项截断必须在固定半径作光滑延拓，不能让 Coulomb 奇点进入中心。对要求有限 ADM 能量的数据另加能量条件。取满足约束的子集 X^s，再取 X^∞；余维声明必须先证明相关约束切片是 Banach 流形。光滑数据族指 p↦Ψ_p 在上述固定拓扑连续/可微，同时各成员光滑；不自动要求 p 的全阶统一 C∞ 控制。

目标 B 的受控族追加：固定 e，固定半径单位 R₀=1；初始标量支撑在统一 [0,R₁]，强范数≤C₀，初始曲率≤C₀，h 一致椭圆，质量和目标 M_f 位于 [M_min,M_max]⊂(0,∞)。需要局部未陷俘余量和对外区的 AF 权重余量；不要求 θ_out 的未加权全空间正下界（其在无穷远趋零）。

## RECCVS-D003：色散、阈值与终态

D⊂X 是未来所有不可延因果测地线完整、I⁺完整，且物质衰减、几何在固定紧区域趋向 Minkowski 的解。必须另指定外区衰减范数才能应用稳定性。N 是未来因果测地完备的非塌缩解；D⊂N。B 是 BH=M\J^-(I⁺) 非空的初值；只有 I⁺及其因果关系已核实才使用这个分类，I⁺完整性另行记录。第二轮修正：I⁺不完整不妨碍在已定义的规则零无穷远部分定义黑洞；不能把完整性偷偷并入所有黑洞或可见奇点的定义。

目标 RECCVS-A001：存在 ε>0、C¹ 约束族 p∈(-ε,ε)，固定 e≠0及统一尺度，满足 p<0∈D，p=0∈B且外部渐近 RN、M_f=|Q_f|>0，p>0 外部渐近亚极端 RN；所有初值满足 D002，且黑洞成员 H⁺∩Σ=∅。这里只要求一条族；随后独立证明 Ψ₀∈∂_X D∩∂_X B和余维性质。不存在此族也可给限定数据类禁止定理。

定义阈值要在 p=0 邻域给完整三分支，不能仅取 sup{p∈N} 后默认所有较小 p 色散。渐近 RN 至少要求外部适当几何范数收敛、视界面积半径趋向 r_+、Bondi/视界终态质量电荷存在，且 M_f>0。M_f 是剩余黑洞质量，通常不是 ADM 质量；辐射带走电荷时 Q_f 也不是 Q_ADM。

## RECCVS-D004：曲率、仿射参数和可见性

曲率标量分别追踪 R、R_abR^ab、K=R_abcdR^abcd；Lorentzian 收缩没有正定性，某个标量有界不能排除潮汐奇点。平行传播框架沿指定因果测地线平行输运，并在固定初始球以 -g(L,n)=1 等方式归一化；禁止随参数任意 boost。

单解曲率奇点要求未来不可延因果测地线 γ:[0,s*)，s*<∞（零线用仿射、类时线用固有时），且至少一个标量或上述固定框架曲率分量无界。这里只得到 C² 延拓障碍；C⁰或弱解延拓需分别判断。坐标奇点、单纯测地不完备与曲率奇点不同。

全局可见奇异边界不写“边界点属于 J^-(I⁺)”这种未定义表达。采用商空间因果边界中奇异端点 b，要求存在过去端趋向 b 的未来出射零线到达同一个已识别的 I⁺，并证明此线在实际时空中的存在及其过去仿射长度有限。该 I⁺是否完整另行记录；加强版可要求它完整，不能无说明地用加强版缩窄用户主问题。另记录较弱定义：γ 上任意接近端点的点可向 I⁺发送信号。两种定义不能未经边界分析互换。

目标 B 的可见曲率是时空内 x∈J^-(I⁺) 的 sup；无穷时增长只给 B 的候选，不给有限仿射端点。标准 ERN 的视界先进时间 v 可取仿射（κ=0）；v→∞是在无限仿射长度处。RN 的 K=48M²/r⁶-96MQ²/r⁷+56Q⁴/r⁸，极端视界 K=8/M⁴，为反误判基准。

一般性在指定 X 拓扑取开稠密或残余，并明确选择；在临界集合 C 内用相对拓扑另定义。余维一指存在局部 C¹ 标量函数 F、DF≠0，使 C=F^{-1}(0)，不是“恰好调一个参数”。弱宇宙审查研究一般 AF 数据的完整 I⁺和奇点可见性；强宇宙审查研究一般 MGH 发展在指定 C²/C⁰/W^{1,2} 类中的不可延拓性。
