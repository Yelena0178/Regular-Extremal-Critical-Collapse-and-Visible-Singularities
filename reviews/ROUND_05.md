# 第五轮：中心电荷—能量的尖锐障碍

接续实际已有 L012–L016 与 ROUND_04。旧对话中的“Liouville 核有希望闭合”在文件中已经写成条件性内部证明 L012；本轮未重复宣称新闭合。L012–L015 仍待独立复核。

新增 L017：对仍连接正则中心、外球标量为零的实际入射截面，证明 S≥4j_{0,1}|Q|/(|e|R²)。使用 Wilson 输运、完成平方及显式加权 ground-state 恒等式。常数在径向函数类中最优；全零外球 jets 给严格性，但不提供统一正间隙。不得把径向等号函数认证为全约束中心填充。

自行核查：平方展开的电流符号；r²坐标变换的两个因子；中心与 Dirichlet 外端的分部积分边项；非零极值的外端导数；截断近似的 O(ε) 能量误差。SciPy 独立积分检查 R=1 的显式等号函数给 S/|J|=9.61930223078309，与 4j_{0,1} 相符。数值只是代数校验，证明在 L017 中。

当前状态：全中心膨胀符号仍未闭合；有限体积、有限中心固有寿命均保留此前的条件性依赖。本轮给出更强的非微扰能量障碍，不声称 A–D 已解决，也不声称文献首创性。
