# A-AF04：旋转候选的具体空间数据与 AF 数值实现

2026-10-21。本文补充 [A-AF03](AF_REALIZATION_WITH_TRANSVERSE_FLUX.md) 到 [A-PATH01](CONSTRAINT_CONTRACTION_AND_FIRST_BOUNDARY.md) 的计算输入。已从两个旋转种子的过去特征薄带提取空间数据，构造有明确实变量公式的光滑紧支撑自由函数，并从平直中心重新求解完整空间约束至 RN 外尾。

**证据等级仍为 E0。** 本次给出了具体候选初值实现，不是原特征种子的精确 AF 实现证书。平滑近似及重解约束改变了实际数据；没有证明原边缘球仍被保留，没有完成重构后候选的早期未来筛选，更没有证明临界曲线或三分支终态。

同日后续：[A-AF05](ROTATING_AF_CONTINUOUS_BARRIER.md)另行冻结规范化自由函数，并对它们完成列明算术假设下的连续半径正性认证。本文 E0 报告保留原证据等级；后续认证不提供原种子的精确转移或任何未来终态结论。

## 1. 空间图、径向规范及精确转换

采用 D001、A-CHG01 的变量，设空间图 u=u(v)、p=u'(v)<0，且图上 λ>0、ν<0。记

    w=λ+pν>0, a=Ω√(−p), f=−4νλ/Ω²,
    n=(−p∂u+∂v)/a, s=(p∂u+∂v)/a.

则面积半径单调，dr/dv=w。诱导空间度量 h=D⁻¹dr²+r²dω²、角向外曲率 ℓ 为

    √D=w/a, ℓ=−(λ−pν)/(ra), D=f+r²ℓ².          (C1)

设 P=D_uφ=νz/r、V=D_vφ=θ/r。原规范 A_v=0，拉回势为 pA_u dv。取

    β(v)=e∫[v_cap,v] p(t)A_u(u(t),t)dt,
    φΣ=exp(iβ)φ,
    φΣ'=exp(iβ)(pP+V)/w,
    χ=Π/√D=exp(iβ)(−pP+V)/w.                  (C2)

这里 β' 的正号来自 D=∇+ieA：规范函数取 −∫pA_u dv 后，空间势为零。直接把原 φ 的普通径向导数当成 C2 会遗漏电磁项。本次两个候选的规范相位总量约为 0.03260、0.02527；该项足以在独立残差检查中被检出。

若 L_u=∂u log Ω²、L_v=∂v log Ω²，直接微分单位法向得到

    k_geom=−[p'+p²L_u−pL_v]/[2Ω(−p)^(3/2)].   (C3)

另一条计算途径是空间动量约束

    k_constraint=ℓ+rℓ'−r√D Re(χ conj(φΣ')).     (C4)

两者可独立比较。原零向质量通量拉回后恰为

    m'=Q²/(2r²)+r²D(|χ|²+|φΣ'|²)/2
                  +r³ℓ√D Re(χ conj(φΣ')).     (C5)

[核验脚本](verify_rotating_af_interface.py)精确检查 C1、C5 的转换和任意 Minkowski 空间图上的 C3–C4。一般有物质图的 C3–C4 则由数值独立微分比较，不混称为精确 PDE 核验。

## 2. 两个实际种子的过去薄带与空间图

[rotating_past_slice.py](rotating_past_slice.py) 使用原 (a,ω)=(0.2,8)、(0.3,4) 种子的特征输入，固定 e=0.6。每个种子保留自身 R、S、v_cap，不重标度。取 δ=0.08R，计算 −δ≤u≤0、0≤(v−v_cap)/S≤1.125 的过去条带。原脉冲后的有限尾只有纵向场为零；未把它替换成 RN 开集。

空间图起于 u=−δ/3，脉冲段 p=−δ/(4S)。在归一化 v∈(1,1.04) 以平坦光滑过渡把 p 接到 λ/ν，此后 ℓ=0。图和径向规范相位同时积分，始终检查其位于已计算条带内。原十二变量核没有因时间方向改变而修改；负 u 步长另以独立 RN 解检查，8/16/32 格端点误差为 1.18×10⁻¹⁰、7.03×10⁻¹²、4.05×10⁻¹³。

对两个种子分别运行 48、96、192 格。下表是 192 格空间图的**采样值**，不是连续下界：

| 原种子 | R | min f | min λ | 图终点半径 | 图终点电荷 |
|---|---:|---:|---:|---:|---:|
| (0.2,8) | 14.53456403 | 0.0006219041 | 0.0002826773 | 14.91689224 | 14.53485943 |
| (0.3,4) | 12.96929103 | 0.0005741219 | 0.0002724245 | 13.29648346 | 12.97008864 |

在固定脉冲内部 0.08≤(v−v_cap)/S≤0.92，五项独立残差均随两次加密下降。192 格中，标量径向规范残差约 4.48×10⁻⁵、2.59×10⁻⁵；质量约束残差约 2.33×10⁻⁴、4.62×10⁻⁴；C3–C4 残差约 1.54×10⁻⁴、3.25×10⁻⁴。省略径向规范后标量残差仍约 0.00490、0.00339。

这些残差区域有明确限制，尤其不把它们当作尾部近零膨胀区域的统一误差证书。双三次插值也不是光滑实际解的严格包络。原数据、有限图和诊断分别保存在 `ROTATING_PAST_SLICE_*_2026-10-21.json/.npz`。

## 3. 明确的光滑自由函数与中心、外尾

[rotating_af_numeric.py](rotating_af_numeric.py) 不直接把三次样条作为 X∞ 输入。它在各面积半径节点提取有限三次 Taylor 多项式 T_i，在相邻节点间以

    H(t)=exp(−1/t)/(exp(−1/t)+exp(−1/(1−t))), 0<t<1,
    H=0 (t≤0), H=1 (t≥1),
    F(r)=(1−H(t))T_i(r)+H(t)T_(i+1)(r)         (C6)

分别定义 φ、χ、ℓ。相邻区间在同一节点都具有同一个 T_i 的全阶 jets，因 H 的端点平坦性，理想实变量公式 C6 是 C∞。系数与节点取已保存数值所给出的具体有限数，不要求它们等于实际解。代码中的指数饱和、舍入与差分仍是该公式的浮点近似，未给向外舍入的函数包络。

中心侧 φ、χ 的起点 jets 设为零；在首个物质半径以下，以同类平坦过渡把 ℓ 接到零。更内侧是精确平直帽，支撑起点为首个物质半径的一半。

外侧先在一个末端网格宽度内把 T_last 平滑冻结为末端常值，再于径向宽度 δ 内降到零；ℓ 在末端极小环带及其外侧恒零。此构造避免把末端高阶 Taylor 多项式直接外推整段宽度 δ。所有自由函数在外支撑端全阶消失。

最后对 (sφ,sχ,sℓ)，分别从 Q=0、f=1 重解 A-PATH01 的 Q、f 约束，**不使用插值得到的质量或电荷作为约束解**。对每个平滑过渡区间单独推进自适应 ODE，防止全局大步长跳过狭窄环带。外支撑端确定 M_ADM、Q_ADM，其外使用精确 RN 空间公式；中心帽和重建的 k、Π、E 由既有约束实现计算。

若这些明确自由函数的精确约束解满足全半径 f>0，则 A-PATH01 的证明适用于其整个 0≤s≤1 收缩路径，并给合法完整 AF 初值。**本次仅数值检查该前提，尚未认证它。** 也没有证明 s=1 保留原种子的有限边缘球或是严格陷俘上端，因此不能直接把它代入 A-PATH01 的首个色散边界选择。

## 4. 重解后的候选与独立检查

主输出为 [候选一报告](ROTATING_AF_A020_W8_N192_2026-10-21.json)、[候选二报告](ROTATING_AF_A030_W4_N192_2026-10-21.json)。两条路径各计算 s=0、0.5、1；s=0 为 Minkowski，s=0.5 的采样 min f 约为 0.1753、0.1815。

| s=1 重构候选 | M_ADM | Q_ADM | 采样 min f | RN 外尾最小 f 的浮点值 |
|---|---:|---:|---:|---:|
| (0.2,8) 来源 | 14.5506889644 | 14.5511814500 | 0.0006219122 | 0.0090972952 |
| (0.3,4) 来源 | 13.0209962682 | 13.0224537675 | 0.0005742411 | 0.0085759651 |

两组采样初始两膨胀均为一正一负。表中质量、电荷是完整空间构造的 ADM 量；它们不是未来 Bondi 参数，不用于判断极端或亚极端终态。

从 96 到 192 格，M_ADM 变化约 1.15×10⁻⁵、8.38×10⁻⁶。固定 192 格自由函数，仅把 ODE 容差从 2×10⁻¹⁰ 收紧到 2×10⁻¹²，M_ADM 变化小于 8×10⁻¹⁰；这区分了源数据/插值变化与约束求解器误差，仍不提供严格误差上界。

[独立核验报告](ROTATING_AF_INTERFACE_CHECKS_2026-10-21.json)另用 Q、m 而非 Q、f 作变量，并使用原带符号的质量源重算。两组在全部平滑拼接端点的最大 f 差约 3.11×10⁻¹¹、2.57×10⁻¹⁰，最大 Q 差小于 4.12×10⁻¹⁰；自由 φ 的解析径向导数与独立五点差分差小于 6.2×10⁻⁹。核验同时要求原空间图的五项残差逐级下降，并拒绝遗漏径向规范的负对照。

复算（从本目录）：

```powershell
python -X utf8 rotating_past_slice.py --n 192 --output ROTATING_PAST_SLICE_A020_W8_N192_2026-10-21.json
python -X utf8 rotating_past_slice.py --n 192 --amplitude .3 --frequency 4 --output ROTATING_PAST_SLICE_A030_W4_N192_2026-10-21.json
python -X utf8 rotating_af_numeric.py ROTATING_PAST_SLICE_A020_W8_N192_2026-10-21.json --output ROTATING_AF_A020_W8_N192_2026-10-21.json
python -X utf8 rotating_af_numeric.py ROTATING_PAST_SLICE_A030_W4_N192_2026-10-21.json --output ROTATING_AF_A030_W4_N192_2026-10-21.json
python -X utf8 verify_rotating_af_interface.py
```

核验器还读取已保存的 48、96 格原图报告；重建这些报告时把前两条命令的格数及输出文件名相应更改。`.npz` 保存具体空间图和重解路径数据，JSON 记录源文件哈希及证据边界。
