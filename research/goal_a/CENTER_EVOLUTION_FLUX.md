# A-EXIT09：中心演化的 L1 通量预算

2026-10-18。内部推导，未经独立审查。将 A-EXIT08 的单锥约束接到演化方程；以下是已存在光滑解上的条件性估计，不是全未来存在定理。

## 1. 面积半径坐标与规范

在 f=1−2m/r>0 的中心区域，以 (u,r) 为坐标，A_r=0，中心时间归一化 g(u,0)=1。定义

g=Ω²/(2λ)=2N/f，b=gf=2N，V=b/2，a=A_u，
Ψ=rφ，h=∂rΨ，φ=Ψ/r，d=h−φ。

这里 a 是变换到 (u,r) 后的连接分量；由于原 A_v=0，它等于原来的 A_u。原固定 v 的协变导数变为

    D = ∂u − V ∂r + i e a.

约束与 A-EXIT06 给出精确关系

    g_r/g = |d|²/r,
    b_r = 2g(m − Q²/(2r))/r²,
    a_r = −gQ/r²,
    D h = V_r d + i e g Q Ψ/(2r²).                 (E1)

特别地 g 从中心向外非减。在 A-EXIT08 的 TV(h)≤τ 假设下，1≤g≤exp(τ²/2)=G。不能沿用外条带的时间归一化后直接把中心 g 设为 1；此处明确重新选择中心时间。

## 2. 中心通量不能丢失

令 z=h/|h|（h=0 时取零），ρ=|h|，c=e g Q/(2r²)。由 E1 得到模长的分布意义通量式

    ∂u ρ − ∂r(Vρ)
      = −V_r Re(conj(z)φ) + Re(i c Ψ conj(z)).     (E2)

可先用 sqrt(|h|²+σ²) 正则化，再在有限区间令 σ→0；规范项 i e a h 不贡献模长。对固定外端 T，精确保留边界通量：

    d/du ∫₀ᵀ |h|dr + |h(u,0)|/2
      = V(u,T)|h(u,T)| + ∫₀ᵀ RHS(E2)dr.           (E3)

中心 f=1 且 g=1，故 V(0)=1/2。外端项为正，不能在有限矩形中删去。若在考察时间段内外端通量的时间积分沿 T→∞ 趋零，并有足够的可积性允许取极限，才得到完整锥上的版本。以下完整锥预算均包含这一假设；不能据此预设无限锥存在。

## 3. 只用单锥范数估计源项

假设 ε=||h||∞，η=∫|h|，τ=TV(h) 有限，且 A-EXIT08 的 δ<1。令 F(r)=∫₀ʳ|h|，则 F≤min(εr,η)，|Ψ|≤F，|Q|≤|e|F²/2。分部积分给

    ∫ F³/r² dr ≤ 3 ε η²/2,
    ∫ F⁴/r³ dr ≤ ε²η².                           (E4)

例如第一式来自 ∫F³/r²=3∫F²F'/r≤3ε∫FF'；第二式来自 ∫F⁴/r³=2∫F³F'/r²≤2ε²∫FF'。原点和无穷端边界项均消失。

质量约束 m_r=f|d|²/2+Q²/(2r²)，以及 A-EXIT08 的 ∫|d|²/r≤τ²/2 给

    ∫ m/r² dr = ∫ m_r/r dr
      ≤ τ²/4 + e²ε²η²/8,
    ∫ Q²/r³ dr ≤ e²ε²η²/4.                       (E5)

这里 m(0)=0，有限总质量确保 m/r 在无穷远为零。于是 E2 两项满足

    ∫ |V_r φ| dr ≤ G ε(τ² + e²ε²η²)/4,
    ∫ |c Ψ| dr ≤ 3G e² εη²/8.                    (E6)

完整锥极限合法时，对任意已存在时间段 [0,U] 有

    η(U) + (1/2)∫₀ᵁ |h(u,0)|du
      ≤ η(0) + ∫₀ᵁ G(u) [ετ²/4
                         + e²ε³η²/4
                         + 3e²εη²/8] du.         (E7)

这些变量是逐锥范数，不能将初始范数直接代入右端。有限外端的版本还须加 ∫V(u,T)|h(u,T)|du。

## 4. 对全局闭合的实际意义

平直无源输运 h(u,r)=h₀(r+u/2) 满足 η(U)+(1/2)∫₀ᵁ|h(u,0)|du=η(0)。E7 保留了这个向中心流出的机制，而单纯估计 ||∂u h||L1 会丢掉它。

但固定的 ε、η、τ 小上界只能令右端误差至多线性随 U 增长，尚不能推出全未来小性。此估计明确提出下一项必要工作：联合控制 ε、τ 的演化，并获得 ετ² 与 εη² 等预算的时间可积性，或利用 E2 中的符号、相位抵消改善 E6。不能靠反复使用单锥小性跳过这一关。

本稿没有证明这些可积性条件，也没有证明色散侧开放性、临界曲线或极端分支。复核脚本仅验证坐标变换代数、通量抵消与积分系数。
