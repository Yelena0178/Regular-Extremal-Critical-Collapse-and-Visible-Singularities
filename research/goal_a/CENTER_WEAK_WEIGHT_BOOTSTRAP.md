# A-EXIT10：同权一阶衰减的条件性闭合

2026-10-18。内部先验推导，尚未经独立复核。目的为推进色散出口的中心传播；本稿不宣称局部存在、无限锥构造、未来完整性或目标 A 已完成。

## 1. 一个容纳启动段的范数

沿用 A-EXIT09 的中心时间、A_r=0 规范。设 j=∂r h，A=1+u，W=A+r。在已存在的光滑中心发展上考虑

    |h(u,r)|, |j(u,r)| ≤ K W^(-3/2).              (W1)

这里 h 与 j 使用同一个权重，没有要求 j 多衰减一阶。长度单位保持项目固定单位，未随 R 或临界参数重缩模型。

A-EXIT07 的回流在中心帽为零；在启动段 h,j=O(R^-2)，其后 h=O(r^-2)、j=O(r^-3)。条带 λ 的上下界使 r 与 ρ 可比。因此在所有已存在初始边段上

    sup (1+r)^(3/2) max(|h|,|j|) ≤ C R^(-1/2).   (W2)

常数独立于边段长度。完整初始锥存在仍须另证，W2 不替代该步骤。这与 A-EXIT06 的 k>2 导数障碍相容。

## 2. 逐锥几何与精确导数演化

W1 给 ε≤K A^-3/2，η,τ≤2K A^-1/2。固定 e=3/5，取 K≤1/8，则 A-EXIT08 给

    2m/r ≤ 4K² + e²K⁴ < 1/2,
    1 ≤ g ≤ exp(2K²/A) < 2,
    1/4 ≤ V=gf/2 ≤ 1.                            (W3)

由 A-EXIT09 和 a_r=−gQ/r²，令 C=e gQ/(2r²)，有

    D h = V_r d + i C Ψ,
    D j = 2V_r j + (V_rr−V_r/r)d
                      + 3i C h + i C_r Ψ.        (W4)

D=∂u−V∂r+i e a，d=h−Ψ/r。第二式的 3iC 包含规范交换子，不能按普通导数交换略去。所有项沿入射特征用酉因子积分，电势 a 本身不产生模长放大。

## 3. 不损失中心幂次的源项估计

下文 C_e 是仅依赖固定 e 的有限常数，可在不等式间增大；不随 K,u,r 或初始壳位置变化。假设 K≤1/8。W4 两个右端均满足

    |S_h| + |S_j| ≤ C_e K³ A^(-3/2)/(A+r)².      (W5)

为使这个估计可逐项审查，分两区推导如下。使用精确关系

    Q_r=e Im(Ψ conj(h))=e Im(Ψ conj(d)),
    m_r=f|d|²/2+Q²/(2r²),
    g_r/g=|d|²/r,
    V_r=g(m−Q²/(2r))/r².                         (W6)

### 近区 0<r≤A

令 μ=min(r,1)。由 d=r^-1∫₀ʳ s j(s)ds 及 |d|≤2ε，得到

    |Ψ|≤Kr A^-3/2,  |d|≤2K A^-3/2 μ,
    |Q_r|≤2|e|K² A^-3 rμ,
    |Q|≤2|e|K² A^-3 r²μ,
    m_r≤C_e K² A^-3 μ²,
    m≤C_e K² A^-3 rμ².                          (W7)

质量估计中的电荷项使用 r≤A、K≤1、A≥1。对 W6 求径向导数，不需 j_r：

    V_rr=(g_r/g)V_r
      +g[m_r/r²−2m/r³−QQ_r/r³+3Q²/(2r⁴)].

故

    |V_r|≤C_e K² A^-3 μ²/r,
    |V_rr|≤C_e K² A^-3 μ²/r²,
    |C|≤C_e K² A^-3 μ,
    |C_r|≤C_e K² A^-3 μ/r.                      (W8)

代入 W4，利用 μ≤1、μ³/r²≤1、r≤A，得

    |S_h|≤C_e K³ A^-7/2,
    |S_j|≤C_e K³ A^-9/2.

由于 (A+r)²≤4A²，增大 C_e 后即为 W5。Q 的 r³ 中心消去是必要的；若仅用总电荷上界，会制造不存在的中心奇性。

### 远区 r≥A≥1

由逐锥质量预算和 W1，

    |Ψ|≤2K A^-1/2, |d|≤3K A^-1/2/r,
    |Q|≤2|e|K²/A,
    m≤K² A^-2+16e²K⁴ A^-3≤C_e K² A^-2,
    m_r≤C_e K² A^-1/r²,
    |Q_r|≤2|e|K² A^-1/2 r^-3/2.

同一导数公式给

    |V_r|≤C_e K² A^-2/r²,
    |V_rr|≤C_e K² A^-2/r³,
    |C|≤C_e K² A^-1/r²,
    |C_r|≤C_e K² A^-1/2/r³.                     (W9)

在 S_h 中最慢的是 CΨ，为 C_e K³ A^-3/2/r²。S_j 的各项更快或受同一界控制：例如 C_rΨ≤C_e K³ A^-1/r³，且 A^1/2/r≤1。再用 (A+r)²≤4r² 得 W5。

## 4. 特征积分真正闭合

对终点 (u,r)，反向入射特征满足 dr_s/ds=−V，故由 W3

    r_s≥r+(u−s)/4,
    1+s+r_s≥(1+u+r)/4,
    1+r_0≥(1+u+r)/4.

特征始终留在非负半径区域并回到 u=0；不需要给中心另加进入区域的边界数据。在所考察区域包含这些特征的前提下，W5 给 h 和 j 各自的估计

    |h|,|j| ≤ 8K₀ W^-3/2
      +16 C_e K³ W^-2 ∫₀ᵘ (1+s)^-3/2 ds
      ≤ [8K₀+32 C_e K³] W^-3/2.                 (W10)

其中 K₀ 是初始同权范数。取

    K≤1/8,  K₀≤K/32,  K²≤1/(128 C_e),

则 W1 改善为 K/2。常数是非有效的充分小阈值；未给指定有限 R 的数值阈值。对满足边界、正则性和加权尾连续性要求的已存在发展，这给出独立于终止时间的严格 bootstrap 改善，而非只有有限时间 Gronwall 增长。

## 5. 消除了什么，仍缺什么

若上述改善通过连续性保持，A-EXIT09 的时间预算可积：ετ²、εη²=O(K³ A^-5/2)，ε³η²=O(K⁵ A^-11/2)。单锥质量 m=O(K² A^-2+e²K⁴ A^-3)，紧致度及光学系数亦衰减。这是已存在发展上的条件性结论。

仍须建立并核对：完整回流锥的远场延拓；满足此范数及中心相容性的局部特征存在与加权连续性；高阶正则性和延拓准则（h,j 的界本身不自动证明它们）；外区拼接及未来因果/零无穷完整性。更不能用一个小出口解替代同一条临界曲线、形成侧或极端终态的证明。

验证脚本核对 W4 的交换子系数和 W10 的可积核，并检查积分预算的幂次；不验证上述完整分析或存在性定理。
