# A-CAUS01：边缘种子的黑洞结论与真正形成的有限逃逸接口

2026-10-20。内部推论及外部定理前提审计，未经独立数学复核。依赖 [A-AF03](AF_REALIZATION_WITH_TRANSVERSE_FLUX.md) 的完整初值实现成立；不将该实现稿或现有 E0 演化升级为独立认证。新增的是全局因果结论及一个可检验的真正形成充分条件，不是 RN 终态或临界曲线。

## 1. 可适用的全局结构定理

本次核对 [Kommemi, arXiv:1107.0949v2](https://arxiv.org/pdf/1107.0949v2)，Theorem 1.1（印刷页 5–8），Corollary 1.2（页 16），及 §5.4–5.7。这里使用的内容是：

- 单端光滑球对称 AF、初始无反陷俘球的 Einstein–Maxwell–Klein–Gordon 发展有连接于该端的唯一出射零无穷远段。
- 表观视界集合 A={λ=0} 与严格陷俘区均不交 J⁻(I⁺)；黑洞区非空时 I⁺ 在论文的 Christodoulou 意义下完整。
- 几何 Hawking–Bondi 质量有非负单调极限；若黑洞区非空，事件视界 H⁺ 非空，且其半径上确界不超过该最终质量的两倍，最终质量严格正。H⁺ 的过去端在初始片或规则中心。

适用性逐项对应：

| 前提 | A-AF03 的输入/输出 |
|---|---|
| 同一物质模型 | D001 是其无质量、无磁荷子情形；固定正归一化不改变能量条件及几何结论，耦合无需小 |
| 光滑球对称约束解 | 实际内球与 l=0 环带在开集匹配，自由函数光滑截止，约束 ODE 延伸 |
| 单端、规则中心、空间完备 | 内部 Minkowski 帽、Σ≅ℝ³、光滑正定紧核与完整 AF 尾 |
| 初始无反陷俘 | 每个正半径初始球 θ_in<0；不是只检查出射膨胀 |
| AF 衰减 | 外部是精确静态 RN 空间尾，标量及其法向导数为零 |
| 实际有限边缘球 | A-AF03 §6 的依赖域与 Cauchy 唯一性保留 r=Q=R>0、λ=0、ν<0 的球 S |

这里不要求全未来无陷俘、不要求边缘球是事件视界，也没有用 RN 稳定性。定理的 I⁺ 完整性不是本项目全部规则共形边界、Bondi 电荷和迟时范数条款的替代品。

## 2. 对两个种子的全局推论

在 A-AF03 实现成立的前提下，任一保留 S 的合法完整 AF 补全均满足

\[
S\notin J^-(\mathcal I^+),\qquad
\mathcal B\ne\varnothing,\qquad \mathcal H^+\ne\varnothing,
\tag{C1}
\]

并有上述定理意义的完整 I⁺。记

\[
\mathfrak M_K=\inf_{\mathcal I^+}\left(\lim m_H\right).
\]

定理给

\[
0<\mathfrak M_K<\infty,\qquad
\sup_{\mathcal H^+}r\le2\mathfrak M_K. \tag{C2}
\]

因此这些已含边缘球的完整初值不属于目标的完整色散集合 D。这项结论不依赖 [A-END01](FINITE_MARGINAL_TAIL_GATE.md) 的 P≠0 条件，且不因未来有无严格陷俘而失效。

必须区分三个尚缺的结论：

1. C1 不保证初始片完全在黑洞外。初始膨胀一正一负同样不能保证这一点。
2. Γ={u=0,v≥v_S} 属于黑洞区不等于 Γ=H⁺。原定理允许表观视界的未来极限落到正半径 Cauchy 边界；它没有消除 A-END01 中的因果身份前提。
3. \(\mathfrak M_K\) 是论文中的几何 Hawking–Bondi 质量。与本项目先取 \(\varpi\) 的零无穷远极限、再取归一化 Bondi 时间晚时极限相认，还须兑现相应提取接口（例如 Q²/r→0）。这里没有得到 Q_f、极端等式、RN 收敛或标量衰减。

## 3. 真正形成可由一个中心逃逸见证完成

下面给针对 A-AF03 补全的充分条件。令 O_Σ 为初始片中心。若实际发展中存在

\[
p\in J^+(O_\Sigma),\qquad r(p)>2M_{\rm ADM}, \tag{C3}
\]

则整个 Σ⊂J⁻(I⁺)，事件视界的过去端为 Σ 之后的实际规则中心事件。结合 C1，这证明项目要求的“真正形成”部分；不证明任何 RN 终态。

证明分三步。

**第一步：所有黑洞点的半径有上界。** 初始无反陷俘及入射 Raychaudhuri 给实际正半径区域 ν<0。对任意黑洞点 p 沿过去入射径向零线向外回溯，半径增加，直到遇到 H⁺ 或 Σ。若先遇 H⁺，直接有 r(p)≤sup_H r。若先遇 Σ 的黑洞部分，该部分在球对称商中位于 H⁺∩Σ 的内侧；初始两膨胀异号给沿 Σ 向外 r 严格增加，故同样有 r(p)≤r(H⁺∩Σ)。这里用到了 Theorem 1.1 中事件视界是黑洞过去边界的单条出射零线及其端点分类。于是

\[
\sup_{\mathcal B}r\le\sup_{\mathcal H^+}r\le2\mathfrak M_K. \tag{C4}
\]

**第二步：比较 ADM。** A-AF03 的外尾 r≥r₁ 是精确 RN 初值，r₁ 在静态外区且 f 在其外保持正。该外尾的未来依赖域包含紧邻空间无穷远的早期 I⁺ 段，由唯一性是同一 RN 外部，那里 Hawking–Bondi 质量等于 M_ADM。I⁺ 上的质量单调性给

\[
\mathfrak M_K\le M_{\rm ADM}. \tag{C5}
\]

把 C4 用于实际边缘球 S，还得到不依赖 RN 收敛的下界

\[
\frac R2\le\mathfrak M_K\le M_{\rm ADM}. \tag{C6}
\]

原[2048 格有理半径证书](EARLY_CHARGED_CONSTRAINT_CERTIFICATE_N2048_2026-10-17.json)的源文件哈希已核对一致；其精确半径下界除以二给两种子的 \(\mathfrak M_K>7.2410\)、\(\mathfrak M_K>6.4505\)。这些下界依赖本稿完整实现及全局定理的前提，不是仅凭一条锥得到的未来终态数值，也不是断言 M_f=R。

因此 C3 的 p 不可能在黑洞区。由因果关系的传递性，O_Σ∈J⁻(I⁺)。

**第三步：从中心到整片。** 全局球对称双零商中，Σ 向外的出射标签 u 严格减小；I⁺ 的出射标签组成从 AF 端开始的一个区间。初始中心可以向 I⁺ 发信号，故比它更外侧的全部初始点亦在 J⁻(I⁺)。等价地，若 H⁺ 与 Σ 相交，其内侧初始中心必在黑洞区，与上一步矛盾。定理给 H⁺ 过去端在 Σ 或规则中心；前者已被排除，且 O_Σ 可见，所以过去端为其后的规则中心事件。

C3 只需一个严格余量和一条实际因果路径，不要求全未来逃逸轨道的数值积分。也可以用“到达任一已被严格识别为可见的实际外区点”替代其半径条件。**当前两种子的 C3 尚未得到证明或数值认证。** 末端球半径约为 R，而 M_ADM≈R，不能把该球本身当作逃逸见证；路径必须从 O_Σ 出发，也不能拿无关的外尾大半径点代替。

## 4. 临界参数不能只放在 AF 补全尾部

若一族完整初值只在 S 的既定过去依赖域之外变化，Cauchy 唯一性保留同一个有限边缘球。C1 对每个成员都成立，因此这族无论是否为 X⁶ 中 C¹，都没有目标所需的完整色散负侧。

这一限制适用于保持有限锥内核不变、只改变 AF cutoff 或外部约束延拓的方案；不排除真正修改内核的临界曲线。A-AF03 的局部 C¹ 实现选择本身不提供跨越 D 的参数。

对全局路线的具体要求因此是：

- 真正形成侧需要来自初始中心的可见性证明，C3 是一个充分的有限域接口；
- 负侧参数必须改变保留 S 的因果内核；外尾补全自由度不能单独完成跨越；
- A-END01 的全局排除仍须另证 Γ=H⁺，不能从本稿的 Γ⊂B 推出；
- 完整早期筛选、形成侧 RN 稳定性和端点的全局阈值控制均未完成。

验证范围：定点核对外部定理、归一化无关的几何前提与上述因果推导；本次没有运行新的二维 PDE 数值，也没有把现有浮点网格当作 C3 的证据。

## 5. 当前早期矩形不能提供中心逃逸见证

原旋转种子的矩形使用 u∈[0,U]、v 从平直帽边至脉冲末端 b；边缘球 S 在 u=0、v=b。设 O 为该出射锥的规则中心顶点，而 O_Σ 是更早初始片的中心，两者不能混淆。

在完整 AF 实现中，C1 与全局球对称因果排序使事件视界出射标签 u_H≤0：I⁺ 的标签是从 AF 端开始的区间；若 u=0 能到达 I⁺，该出射锥上的 S 也可见，与 C1 矛盾。因此实际矩形内所有 u≥0 的点都位于黑洞区（可包括视界）。这不是对浮点网格的分类，而是对任何保留 S 的完整实现的条件性几何结论。矩形中两膨胀异号并不与之冲突。

在同一矩形，ν<0 又给

\[
r(u,v)\le r(0,v)\le R. \tag{C7}
\]

对于 A-AF03 的充分小固定 δ，M_ADM=R+O(δ²)，所以 C7 甚至在半径上也达不到 C3。有限过去薄带的 r≤R+Cδ 同样不足以达到 2M_ADM。故增加该矩形的网格密度或仅加长末端边缘零尾，均不能产生所需的中心逃逸见证。

下一项实际输入须包括：固定一个具体合法 AF 补全及 M_ADM 的上界；从 O_Σ 而非 O 出发，在 u<0 区域追踪因果路径；覆盖路径经过的实际外部补全；在有限终点认证 r 的下界大于两倍 ADM 上界。当前没有提供这些输入。C7 也说明有限锥本身无法决定真正形成：早期筛选与初始中心可见性需要不同的因果区域。
